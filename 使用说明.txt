成信大校园网助手 v0.1（试用版，非官方）
适用：成都信息工程大学航空港校区，Windows 10/11 64 位，已安装 Microsoft Edge。

开始使用
1. 先连接学校 Wi-Fi 或校园网网线。
2. 双击 CUIT-AutoLogin.exe，无需安装 Python，无需管理员权限。
3. 填写自己的校园网账号和密码，选择中国电信、中国移动、中国联通或校园网。
   选择必须与本人开通的套餐一致；程序不能开通或切换套餐。
4. 在学校认证页面阅读免责声明、隐私协议后，在本程序勾选已阅读并同意。
5. 首次保留“显示登录浏览器”，点击“保存并开始”。
   程序使用独立的临时 Edge 会话，不读取你日常浏览器的密码和登录资料。
6. 登录成功后可最小化程序，继续监测。默认点击右上角 × 或最小化按钮会隐藏
   任务栏窗口，保留右下角通知区域的蓝色校园网图标（可能在小箭头内）。
   点击托盘图标或右键选择“显示窗口”可恢复，右键“退出程序”可完全退出。
   “点击 × 时”可选择最小化到托盘或退出，选择后立即生效并自动记住，无需重新开始登录。
   最小化不会停止正在运行的监测，也不会自动启动尚未开始的监测。
   选择退出，或点击“退出程序”按钮，会停止监测并退出，不会主动下线校园网。

自动运行
需要开机自动运行时，勾选“记住密码”和“Windows 登录后自动运行”，再保存。
使用当前用户的启动项，无需管理员权限。将程序放在固定位置后再启用。
勾选设置要点击“保存并开始”才生效；运行中请先停止，再修改设置。
取消自动启动后再次保存，或点击“清除保存信息”，即可删除本工具的启动项。

分享给同学
发送原始 CUIT-AutoLogin-试用版.zip 即可。每个人输入自己的账号并选择运营商。
发布包没有账号、密码、会话信息。不要分享自己的 settings.json。
本机配置：%LOCALAPPDATA%\CUIT-AutoLogin\settings.json。
账号和偏好以普通文本保存；只有勾选记住密码才保存经过 Windows DPAPI 加密的密码。
密码绑定当前 Windows 用户，不能直接复制到另一台电脑使用。
运行时密码须提供给学校认证页面；学校目前使用 HTTP，程序不改变学校的传输方式。
不记录账号密码日志，不上传到作者服务器，不收集统计信息。

系统自动弹出的认证页
联网后可关闭已识别的 Edge 校园网认证标签页，不关闭整个浏览器。
识别限定为 10.254.241.66 的认证流程网址，关闭前再次校验原标签页身份和网址。
仅处理能安全核对网址的当前选中标签页；不会切换你的其他标签页来查找。
没有弹窗时不做关闭操作。启动和重连后的约 2 分钟内随网络监测补查晚到的弹窗。
若你切换到了其他网页，会跳过关闭；不修改 Windows 联网检测设置。
此功能调用 Windows UI Automation，不读取网页密码，也不记录浏览记录。

连接检查及限制
外网检测使用 Microsoft 的两个联网检测地址，要求响应正文匹配。
单轮检测失败不会立即打开认证页：间隔 5 秒再复查两轮，连续三轮均失败才尝试认证。
任一轮恢复联网就取消本次认证；复查期间点击停止或退出可以中断等待。
持续无法访问检测地址仍可能造成误判，检测失败并不等同于校园网账号已下线。
已经能上网时会跳过登录，因此更改运营商不会强行断开现有连接。
VPN、路由变化或检测地址被拦截可能影响检测结果。
外网正常不等于确认流量经所选运营商；具体运营商由学校认证系统决定。
入口暂时打不开时，监测模式每隔约 30 秒重新检查。
错误密码或未识别页面会停止继续提交，避免反复尝试。
登录期间每约 3 秒发起一次外网检测（请求本身也需要时间）。
检测到外网可用或页面明确提示成功后，自动关闭本工具打开的临时登录浏览器。
手动关闭登录浏览器不会停止后台监测；监测模式约 30 秒后再次检查网络。
未识别结果时，显示浏览器模式会保留窗口，并继续检测联网；联网后自动关闭。
程序只在 10.254.241.66 的网页中填写凭据。
如登录流程新增验证码、运营商密码或页面改版，需要手动处理或更新适配。

源代码
campus_login.py 为完整源代码。
构建依赖：Python 3.12，playwright==1.63.0，pyinstaller==6.22.3，pystray==0.19.5，pillow==12.3.0。
构建命令（在源码文件夹内运行）：python -m PyInstaller --onefile --windowed --name CUIT-AutoLogin --hidden-import pystray._win32 --icon campus-icon.ico --add-data "campus-icon.ico;." --add-data "close_portal_tab.ps1;." campus_login.py
使用系统 Edge，不需要 playwright install 下载另一套浏览器。
Playwright 官方浏览器说明：https://playwright.dev/python/docs/browsers
